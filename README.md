# Projet 5DEV5

Ce dépôt contient les sources du projet WeatherApp.

## Description

L'application permet de consulter la météo. Elle peut aussi afficher une prévision des prochains jours, le nombre de jours est décidé par l'utilisateur. Il peut choisir le nom d'une ville à ajouter ou activer la géolocalisation

## Service rest

Pour collecter les données relatives à la météo, l'API open météo est utilisé.

## Traduction

L'application sera disponible en français et anglais. Un API sera utilisé pour traduire le nom de la ville lorsqu'elle est entré dans la barre de recherche.

## DataStore

Les préférences de l'utilisateur seront sauvegardé selon les préférences choisis dans les paramêtres (ville à afficher en démarrant l'app, nombre de jours, langues)
